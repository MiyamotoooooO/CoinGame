RECORD DROP オープニングムービーの素材
==========================================

■ フォルダ
  Cut01〜Cut10 … カットごとのレイヤー（1920×1080、背景透過 PNG）。ファイル名の先頭の数字が重ねる順（01 がいちばん奥）。
                  全部のレイヤーが同じ大きさなので、同じ位置に重ねるだけで完成イメージになる。
                  レイヤーごとに別の速さで動かすと、奥行きのある動き（パララックス）になる。
  Characters   … キャラクター単体（ヴィニー・ネオン・コバン・メダリオ・ミスター・ミュート・幹部4人のシルエット）。余白を切った透過 PNG。
  Props        … 小物単体（レコード盤・飛行船・メダル・飛んでいくレコード）。
  Overlay      … 全カットの上に重ねる物（Vignette＝四すみを暗くする、Scanlines＝ブラウン管の横線）。
  Preview      … カットごとの完成イメージと、絵コンテ一覧。
  opening_cuts.json … カットごとの秒数・重ねる順・レイヤーのファイル・せりふ・音の一覧（Unity のスクリプトで読む用）。

■ カットごとの注意
  Cut04 … 同じレイヤーの「色あり」と「_gray（灰色）」の2組がある。
           色ありの上に灰色を重ね、灰色の見える範囲を右から広げていくと「色が消えていく」になる。
  Cut05・Cut07 … 最初から灰色にしてある。
  Cut06 … 03_medal だけ色あり（灰色の店の中で、メダルだけ光る）。
  Cut07 … 05_cloth（ずり落ちた布）と 06_cloth_before（かぶっている布）がある。cloth_before から cloth に動かす。
  Cut08 … 04_spin_lines を回すと、ヴィニーの頭が回って見える。
  Cut10 … 05_logo_temp は仮のロゴ。保存したロゴ PNG（RecordDrop_Logo）に差し替える。
  せりふの帯（caption）は文字入り。Unity の文字で出す時は caption のレイヤーを使わず、opening_cuts.json の captions を使う。

■ フォント
  日本語：Noto Sans CJK JP Black、英字：Inter Black で描いている（ロゴの本来のフォントは Bungee）。

■ Unity への取り込み
  1. このフォルダを Assets/Opening などにドラッグする
  2. PNG を全部選び、Texture Type を「Sprite (2D and UI)」にして Apply
  3. 大きい画像なので、Max Size は 2048 にする
